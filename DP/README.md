# برنامه آنلاین انبارداری DP

این پوشه یک برنامه مستقل PHP/MySQL برای نصب در مسیر `akhaco.com/DP` است و با PHP 8.1 و هاست cPanel سازگار است.

## نصب سریع روی cPanel

1. پوشه `DP` را در `public_html` دامنه آپلود کنید.
2. در MySQL Database Wizard یک دیتابیس و کاربر اختصاصی بسازید و کاربر را به دیتابیس وصل کنید.
3. فایل `DP/config/config.sample.php` را به `DP/config/config.php` کپی کنید و مشخصات دیتابیس را وارد کنید.
4. از phpMyAdmin فایل `DP/schema.sql` را روی دیتابیس اجرا کنید.
5. آدرس `https://akhaco.com/DP` را باز کنید.
6. ورود اولیه: نام کاربری `admin` و رمز `admin12345` است. پس از ورود رمز را از بخش کاربران تغییر دهید.

## امکانات

- تعریف، ویرایش و حذف کالا، دسته‌بندی، واحد کالا و انبارها
- ثبت ورود، خروج، انتقال و اصلاح موجودی
- بارکد Code39 برای کالا و شماره ثبت حواله، با چاپ و دانلود SVG
- مشاهده موجودی لحظه‌ای، جستجوی سریع، هشدار حداقل موجودی
- گزارش گردش کالا، کالاهای راکد و کسری/مغایرت
- ثبت تامین‌کنندگان، مشتریان، کاربران و نقش‌های دسترسی
- رابط ریسپانسیو و مناسب موبایل با ذخیره خودکار فرم‌ها در مرورگر
